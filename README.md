# Magic Casting - расширение SillyTavern

Кастование заклинаний рисованием символов пальцем.

## Установка
**Через менеджер:** Extensions → Install extension → вставьте ссылку этого репризетория, а именно https://github.com/Lopersigmula/Magic-Casting

**Вручную:** скопируйте папку `MagicCasting` в
`SillyTavern/public/scripts/extensions/third-party/MagicCasting`
(или в `data/<пользователь>/extensions/MagicCasting` — для установки «только для пользователя»), затем перезагрузите страницу (Ctrl+F5).

### Android / Termux
1. В Termux: `cd ~/SillyTavern/public/scripts/extensions/third-party`
2. Если архив на телефоне: `termux-setup-storage`, затем `unzip ~/storage/downloads/MagicCasting.zip`
3. Перезапустите SillyTavern (`Ctrl+C`, `./start.sh` или `node server.js`) и обновите страницу в браузере.
4. Появится дополнительный пункт «Magic Casting» в меню расширений (волшебная палочка у поля ввода).

## Использование
Откройте ✦ → введите заклинание → «Начать кастование» → рисуйте по подсвеченной линии от фиолетовой точки по стрелке. Кнопка ▾ сворачивает панель (игра ставится на паузу), ✦ открывает обратно. ⚙ — все настройки.

Если у символа несколько штрихов, отрывайте палец между ними. Ошибка — неверное направление, оборванная или слишком длинная линия, большое отклонение.

## Настройка нейросети. Сама нейросеть используется только лишь для оценки сложности заклинания, но не более. Подключать нейросеть можно по своему усмотрению
* **Подключение SillyTavern** (по умолчанию) — используется уже настроенный API (`generateRaw`), отдельный ключ не нужен.
* **Отдельный API** — OpenAI-совместимый адрес (например `https://api.openai.com/v1`), ключ, модель, доп. параметры JSON. Кнопка «Проверить подключение». Запросы идут прямо из браузера: сервис должен разрешать CORS.
* Ключ хранится в настройках SillyTavern (`settings.json` на вашем сервере), в код и журнал не попадает.
* **Режим без API** или сбой ответа → сложность по умолчанию, либо выберите 1–5 вручную на главном экране.
* Ответ ИИ проверяется: неизвестные id символов отбрасываются, числа ограничиваются диапазонами.

## Свои символы
Добавьте объекты в `data/user-symbols.json`:
```json
{ "id": "my_sign", "name": "Мой знак", "tier": 3,
  "strokes": [ { "pts": [[0.2,0.2],[0.8,0.5],[0.2,0.8]], "closed": false } ] }
```
Координаты 0–1 (y вниз), до 6 штрихов, `closed: true` для замкнутых фигур. Новые id автоматически видны ИИ.

## Если что-то не работает
| Проблема | Решение |
|---|---|
| Нет подпункта в меню расширений| Обновите страницу (Ctrl+F5); проверьте путь `…/third-party/MagicCasting/manifest.json`; включите расширение в блоке Magic Casting. |
| Ошибка в консоли про `extensions.js` | Путь папки изменён — расширение должно лежать ровно на уровне `third-party/<Имя>/`. |
| «Нейросеть недоступна» | Проверьте подключение API в ST или нажмите «Проверить подключение»; игра работает и без него. |
| Отдельный API не отвечает | CORS или неверный адрес; используйте «Подключение SillyTavern». |
| Не отправляется в чат | Откройте чат с персонажем; либо выберите «Вставить в поле ввода». |
| Страница скроллится при рисовании | Обновите расширение/страницу; рисуйте внутри поля со светящейся рамкой. |
| Слишком строго/легко | ⚙ → «Строгость распознавания» и «Поправка к ошибкам». |
| Лагает на слабом телефоне | ⚙ → «Анимации: отключены». |

> Совместимость: рассчитано на SillyTavern ≥ 1.12 (`getContext`, `generateRaw`, слэш-команды `/send`, `/trigger`). Загрузку в вашей сборке стоит проверить вручную — расширение тестировалось на уровне модулей без запущенного ST.
